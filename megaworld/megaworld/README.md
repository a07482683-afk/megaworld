# Mega World 0.8.0 (Fabric 1.20.1)

Исходники мода. Чтобы получить .jar, см. GitHub Actions (файл .github/workflows)
или запусти build.bat (нужен JDK 17). Готовый файл: build/libs/megaworld-0.8.0.jar

Установка: Fabric Loader 1.20.1 + Fabric API 1.20.1 + megaworld-0.8.0.jar в папку mods.

## Житель Грокса и чат
Подойди к жителю (до 8 блоков) и пиши в обычный чат: «привет», «за мной», «стой», «как дела»,
комплименты, угрозы... Он отвечает, меняет эмоцию (лицо меняется) и выполняет команды.

Необязательно: ответы от локальной ИИ-модели (Ollama). В файле .minecraft/config/megaworld.json
поставь "aiEnabled": true. Тогда текст твоих сообщений рядом с жителем отправляется на адрес aiUrl
(по умолчанию твой компьютер, http://localhost:11434). По умолчанию выключено.

## Команды жителям (пиши в чат рядом с жителем, до 8 блоков)
Чтобы команду выполнили ВСЕ жители в радиусе 16 блоков, добавь слово «всем» или «жители».
- Движение: «за мной», «иди сюда», «стой», «гуляй», «иди вперёд / назад / влево / вправо 15 блоков»,
  «это твой дом» + «иди домой», «стоп».
- Предметы (рюкзак на 9 ячеек): «собери дерево», «принеси железо», «отдай всё», «выбрось камень»,
  «что у тебя в рюкзаке». Предметы: дерево, камень, руды, металлы, еда, цветы, инструменты и многое другое.
- Жесты: «танцуй», «помаши», «крутись», «прыгай», «спой».
- Эффекты и разговоры: «беги» (скорость), «свети», «спрячься», «расскажи шутку»,
  «который час», «какая погода», «где мы».
Угрозы («убью») команды отменяют: житель пугается.

## Типы жителей и голоса (версия 0.8.0)
Модель жителя — обычная ванильная. Поверх головы рисуется «мемное» лицо по эмоции.
В творческом меню есть яйца для каждого типа (а обычное яйцо создаёт случайный тип):
- Житель Грокса — обычный; лицо меняется только при эмоциях. Голос: обычный житель.
- Житель-придурок — косые глаза, веснушки, язык; медленный; иногда сам прыгает и крутится,
  а команды иногда путает. Голос: осёл и коза.
- Житель-плакса — вечно со слезами, плачет от одного удара. Голос: мяуканье.
- Житель-злюка — хмурый, злится с первого удара. Голос: хрюканье пиглина.
- Житель-трусишка — вечно напуган, быстрый, от удара убегает. Голос: курица.
- Житель-весельчак — всегда улыбается, любит танцевать. Голос: попугай.

Свои звуки: звуки сейчас собраны из ванильных (в игре нельзя создать новый звук без файла .ogg).
Чтобы добавить свои записи, нужны файлы .ogg (Vorbis) и запись в sounds.json мода.
